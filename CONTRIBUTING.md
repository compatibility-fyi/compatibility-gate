# Contributing

Contributions are welcome. Keep changes focused, add tests for behavior changes, and use
conventional commits.

Before submitting a pull request, run:

```sh
npm ci
npm run validate
git diff --exit-code -- dist
```

`dist/` is generated by `npm run build` and must be committed. `dist/index.js` is the GitHub Action
bundle and `dist/cli.js` is the GitLab container CLI bundle. Do not edit bundled files manually.

Changes to `gitlab/compatibility-gate.yml`, the GitLab CLI, or the container must preserve the
fail-closed behavior and include tests. Release images are built from the committed CLI bundle by
the `Container` workflow.
